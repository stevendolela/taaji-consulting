## 🚀 Installation

### Prérequis
- Un navigateur web moderne (Chrome, Firefox, Safari, Edge)
- Un éditeur de code (VS Code recommandé)
- Un serveur web local (optionnel pour le développement)

### Étapes

1. **Cloner ou télécharger le projet**
   ```bash
   cd "Taajii Consulting"
   ```

2. **Lancer un serveur local**
   
   **Avec Python :**
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   ```
   
   **Avec Node.js :**
   ```bash
   npx http-server -p 8000
   ```
   
   **Avec VS Code et Live Server :**
   - Installer l'extension Live Server
   - Clic droit sur `index.html` > Open with Live Server

3. **Accéder au site**
   - Ouvrez votre navigateur : `http://localhost:8000`

## 🌐 Déploiement

### Option 1 : GitHub Pages (Recommandé)

1. **Créer un repository GitHub**
   ```bash
   git init
   git add .
   git commit -m "Initial commit - TAAJI CONSULTING website"
   git branch -M main
   git remote add origin https://github.com/votre-username/taajii-consulting.git
   git push -u origin main
   ```

2. **Activer GitHub Pages**
   - Allez dans Settings > Pages
   - Source : Deploy from a branch
   - Branch : `main` / `root`
   - Cliquez sur Save
   - Votre site sera accessible à : `https://votre-username.github.io/taajii-consulting`

### Option 2 : Netlify

1. **Déploiement en glisser-déposer**
   - Allez sur [netlify.com/drop](https://app.netlify.com/drop)
   - Glissez-déposez le dossier du projet
   - Site en ligne instantanément !

2. **Via Git (recommandé pour les mises à jour)**
   - Connectez votre repository GitHub
   - Netlify déploiera automatiquement à chaque push
   - Configuration : Build command vide, Publish directory : `.`

### Option 3 : Vercel

```bash
npm install -g vercel
vercel
# Suivez les instructions interactives
```

### Option 4 : Hébergement Classique (cPanel/FTP)

1. Connectez-vous via FTP (FileZilla, etc.)
2. Uploadez tous les fichiers dans `public_html` ou `www`
3. Configurez votre nom de domaine dans le panneau d'administration

## 🎨 Personnalisation

Le site utilise une palette cohérente définie dans `css/style.css` :


## 📧 Configuration du Formulaire de Contact

Actuellement en mode démo. Pour activer l'envoi réel :

### Option 1 : Formspree (Gratuit jusqu'à 50/mois)
```html
<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
```

### Option 2 : EmailJS (Gratuit jusqu'à 200/mois)
Intégrez EmailJS dans `js/script.js` pour l'envoi sans backend.

### Option 3 : Backend PHP
Créez `send-email.php` sur votre serveur et mettez à jour l'action du formulaire.
