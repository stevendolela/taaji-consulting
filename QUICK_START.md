## 📞 Aide Rapide

**Erreurs courantes :**

**1. Images ne chargent pas**
→ Vérifiez les chemins : `images/nom-fichier.png`

**2. CSS ne s'applique pas**
→ Videz le cache : Cmd+Shift+R (macOS)

**3. Google Maps ne s'affiche pas**
→ Vérifiez votre clé API Maps

**4. Formulaire ne fonctionne pas**
→ Normal en local, configurez Formspree ou backend
